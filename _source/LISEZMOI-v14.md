# Rubrique « Reconditionnés » (26/10/2026) : 6e usage des PC portables

- **Marchand** : PC-Portable.net, programme Effinity (commission 8 %, fenêtre de 30 jours). Liens des fiches = liens suivis du flux produits (compteur `23326809`) ; deeplink générique du marchand = compteur `23324865` (ne pas utiliser `23324866`, support « INFO 2R » inconnu).
- **Données** : `catalog_reconditionnes.py` (10 modèles : textes, notes lues à la source le 26/10/2026, annonce retenue dans le flux). `python3 _source/build_reco.py` les fusionne dans `data.json` (sans toucher aux autres produits) puis lit le flux.
- **Prix** : `python3 _source/pcportable.py` (aperçu) puis `--apply`, à lancer chaque vendredi avec `effinity.py`. Le flux n'a pas d'EAN : chaque produit garde l'identifiant d'annonce (`ppid`) ; si l'annonce disparaît, une équivalente est cherchée (Windows 11 d'abord, 8 Go minimum, AZERTY). Le prix affiché est celui de la configuration indiquée (`PRIX_EXACTS` dans `gen10.py`). Clé du flux : `_source/effinity.local.json`, clé `url_pc_portable` (jamais dans le dépôt).
- **Notes** : les tests portent sur le modèle neuf. Notebookcheck note sur 100 (note du site = % / 10). LaptopMedia et LaptopMag ne notent pas : tests cités sans note. Aucune photo pour l'instant (`img` vide, « Photo à venir ») : à décider.
- **Générateur** : usage `reconditionne` dans `LCATS` (`gen10.py`), guide `GUIDE_RECO`, `RECO_NOTE` (mention reconditionné sur les offres), pastille « Reconditionné, grade B » en fiche, CSS `extra20.css`. Prochains fichiers : `extra21.css`, `main14.js`. Badge `badge-reconditionne.webp` = copie provisoire de `badge-lowcost.webp` (illustration à demander).
- **Python** : `gen10.py` exige Python 3.12 (f-strings) ; sur la VM de l'application, Python 3.10 par défaut : utiliser `uv` + `uv python install 3.12`.
